Курсовая работа по дисциплине «Базы данных».
Выполнил: Коник Илья, студент 2 курса группы МОА-241
КемГУ, Институт цифры.

## Стек
- Node.js + Express
- MongoDB (Mongoose/драйвер)
- EJS, Bootstrap 5
- bcryptjs, express-session

## Запуск

1. Установить MongoDB и запустить `mongod`.
2. Установить зависимости:
   npm install
3. Инициализировать базу тестовыми данными:
   node init.js
4. Запустить сервер:
   node server.js
5. Открыть http://localhost:3000, зарегистрироваться.

## Структура
- init.js — создание коллекций и тестовых данных
- queries.js — 10 характерных запросов MongoDB
- server.js — сервер прототипа
- views/ — EJS-шаблоны страниц
