# Инструмент для управления проектами

Курсовая работа по дисциплине «Базы данных».  
Выполнил: Коник Илья, студент 2 курса группы МОА-241  
КемГУ, Институт цифры, 2026

## Стек
- Node.js + Express
- MongoDB (native driver)
- EJS, Bootstrap 5 (CDN)
- bcryptjs, express-session

## Возможности
- Регистрация и вход с ролями: admin, manager, member
- Создание и управление проектами (статусы, приоритеты)
- Канбан-доска задач (todo, in_progress, review, done)
- Назначение исполнителей, сроки, комментарии
- История изменений по задачам
- Админ-панель: блокировка и разблокировка пользователей

## Запуск
1. Установить и запустить MongoDB (`mongod`)
2. `npm install`
3. `node init.js`
4. `node server.js`
5. http://localhost:3000

## Структура проекта
- `init.js` — создание коллекций и тестовых данных
- `queries.js` — 10 характерных запросов MongoDB
- `server.js` — сервер прототипа (Express + EJS)
- `views/` — шаблоны страниц
